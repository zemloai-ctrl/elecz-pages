Three MCP tools. Every electricity use case covered.

Elecz exposes three tools over the Model Context Protocol. The agent picks the right one based on the user's question — no prompt engineering needed.

spot_price
Current electricity spot price for any supported zone. Returns price, unit, timestamp, and data source. Called when a user asks "what is the electricity price right now?" If the live feed is briefly unavailable, the response includes fallback: true — agents should not present this as a confirmed current price.
→ price, zone, currency, unit, timestamp, source, fallback
cheapest_hours
Ranked cheapest hours today and tomorrow. Includes current-hour signal and next cheap window. Called for scheduling questions — EV charging, heat pump, dishwasher, batch jobs. Requires public day-ahead data — not available for AU, NZ, KR, US-TX (ERCOT), ZA, or PH-*. Full field reference →
→ ranked_hours, current_hour_signal, cheap_window_ends, next_cheap_hour
best_energy_contract
Live contract options with savings estimate. Best spot contract, best fixed contract, overall recommendation, direct switch link. Called when a user asks about saving money on electricity.
→ best_spot, best_fixed, recommended, savings_estimate, provider_url

Frequently asked questions

What is the difference between an MCP server and a connector?
Same thing, different name depending on the platform. Developer documentation calls it an MCP server. AI platforms like Glama, Claude, and Grok call it a connector. Elecz is listed as a connector on Glama (com.elecz) and as an MCP server in developer registries. The endpoint is always: https://elecz.com/mcp.
What is an electricity price MCP server?
MCP (Model Context Protocol) is an open standard that lets AI agents call external tools during a conversation. An electricity price MCP server gives the agent access to live electricity data — so instead of guessing, it fetches the real price on demand. Elecz exposes three tools: spot_price, cheapest_hours, and best_energy_contract.
How do I add an electricity price MCP server to Claude?
In Claude.ai: Settings → Integrations → Add MCP server → paste https://elecz.com/mcp. In Claude Desktop: add to claude_desktop_config.json under mcpServers. No API key required — just the URL.
How do I add an electricity price MCP server to Grok?
In Grok, click the "+" next to the prompt field, choose Add MCP server, and paste https://elecz.com/mcp. No API key or account required — Grok can call spot_price, cheapest_hours, and best_energy_contract immediately after connecting.
Is the Elecz MCP server free?
Yes. All three tools — spot prices, cheapest hours, and contract comparison — are free. No API key, no account, no registration required.
Which countries does the electricity MCP server cover?
40+ countries across Europe, Oceania, North America, Asia, and Africa. All ENTSO-E zones in Europe, UK via Octopus Agile, Australia (5 zones), New Zealand, USA (CAISO, ERCOT, NYISO), Canada (Ontario/IESO), South Korea, Japan (9 JEPX zones), South Africa (Eskom regulated), Philippines (Meralco/ERC regulated), and Mexico (14 CENACE zones). Full list at elecz.com/electricity-price-api.
Does the electricity MCP server work in Australia?
Yes. Elecz covers all 5 Australian NEM zones: AU-NSW, AU-VIC, AU-QLD, AU-SA, and AU-TAS. The NEM dispatches and prices the market every 5 minutes — Elecz fetches this data on the same 5-minute cadence. Note: cheapest_hours is not available for Australia — AEMO does not publish public day-ahead price forecasts.
Which zones does cheapest_hours not support?
cheapest_hours requires public day-ahead market data and is not available for Australia, New Zealand, South Korea, US-TX (ERCOT), South Africa, or the Philippines (PH-LUZ, PH-VIS, PH-MIN) — these markets publish only current or regulated prices, not day-ahead forecasts. spot_price still works for all of them.
What happens if the live price feed is temporarily unavailable?
The response includes a fallback field. When fallback: true, the returned price may not reflect the current live market — agents should not present it to a user as a confirmed current price.
Does it require a local installation?
No. Elecz uses streamable HTTP transport — the agent connects directly to https://elecz.com/mcp over the internet. No npm install, no Docker, no local process needed.
What transport does the MCP server use?
Streamable HTTP (the current MCP standard for remote servers). This works with Claude.ai, Claude Desktop, Cursor, Copilot, Windsurf, Grok, Mistral, ChatGPT, and all other MCP clients that support remote HTTP servers.
