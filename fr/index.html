Le prix de l'électricité n'est pas du contenu. C'est une donnée d'entrée.

Le prix se comporte comme un cours boursier ou une météo — il a une valeur précise à cet instant, et cette valeur change chaque heure. Un modèle de langage retourne une moyenne historique. Une recherche web peut trouver le prix du jour, mais on ne peut pas construire une automatisation fiable là-dessus. Il faut un appel API structuré avec un résultat lisible par machine — à chaque fois, avec un schéma connu.

Pourquoi ne pas simplement demander à une IA ?

Les modèles de langage sans outils temps réel sont aveugles aux marchés de l'énergie. La différence entre une réponse correcte et une réponse hallucinée peut atteindre un facteur 200.

France — ce qu'il faut savoir

Elecz fournit le prix de gros ENTSO-E pour la France (zone FR) en EUR ct/kWh TTC.

Cette page décrit principalement le marché français (zone FR). La Belgique (BE), les Pays-Bas (NL) et la Suisse (CH) sont également supportés — prix spot et heures les moins chères disponibles, comparaison de contrats actuellement uniquement pour FI, SE, NO, DK, DE et GB.

  • Prix hors tarif d'acheminement (~8–12 ct/kWh, variable selon la région)
  • Prix hors taxes et contributions (CSPE, CTA, TVA etc.)
  • Prix spot de gros — différent du tarif réglementé de vente (TRV/TRVE)
  • Prix horaires depuis ENTSO-E, mis à jour toutes les heures
  • Prix du lendemain disponibles à partir de 13h00–14h00 CET

Questions fréquentes

L'API prix d'électricité Elecz est-elle gratuite ?
Oui. Les prix spot et les heures les moins chères sont toujours gratuits — aucune clé API, aucun compte, aucune inscription. La comparaison de contrats est également gratuite.
Pourquoi ne pas simplement demander le prix à ChatGPT ou Claude ?
Les modèles de langage n'ont pas accès aux marchés en direct. Sans outil temps réel, le modèle retourne une moyenne historique — pas le prix actuel. Le prix spot réel peut être 0,0 ct/kWh lors d'un surplus d'énergies renouvelables ou 50+ ct/kWh lors d'une crise réseau. Une estimation est sans valeur pour toute décision réelle.
Existe-t-il une API gratuite de prix d'électricité pour la France ?
Oui — Elecz est gratuite pour la France. Prix spot et heures les moins chères disponibles pour la zone FR sans clé API ni inscription. Données depuis ENTSO-E, mises à jour toutes les heures.
Qu'est-ce que MCP et pourquoi est-ce pertinent pour les données d'électricité ?
MCP (Model Context Protocol) est un standard ouvert pour connecter des agents IA à des outils externes. Les prix de l'électricité changent chaque heure — un agent a besoin d'un appel API en direct, pas de données d'entraînement. Elecz est MCP-first : connexion via https://elecz.com/mcp, aucune configuration requise.
À quelle fréquence les données sont-elles mises à jour ?
Toutes les heures depuis ENTSO-E pour les zones françaises et européennes. GB toutes les 30 minutes (Octopus Agile). Les prix du lendemain sont disponibles à partir de 13h00–14h00 CET environ.
Elecz fonctionne-t-il avec Home Assistant ou d'autres systèmes d'automatisation ?
Oui — via l'API REST ou le node n8n, Elecz s'intègre à toute plateforme d'automatisation. Pompe à chaleur, lave-vaisselle et recharge de véhicule électrique sont des cas d'usage typiques. Le champ current_hour_signal retourne directement low, medium ou high — aucune logique personnalisée nécessaire.
