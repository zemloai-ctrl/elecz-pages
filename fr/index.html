Trois outils. Tous les cas d'usage couverts.

Elecz expose trois outils MCP — pour le prix spot actuel, la planification des heures les moins chères et la comparaison de contrats là où elle est disponible. Référence complète des champs dans la documentation API prix électricité.

Prix spot actuel pour la zone FR et toutes les zones supportées. Prix, unité, horodatage, source.

Construire des agents IA conscients du prix de l'électricité

Un agent IA ne peut pas déduire le prix actuel de l'électricité à partir de ses données d'entraînement — il change chaque heure, parfois du simple au décuple en une journée. Un agent conscient de l'énergie a besoin d'un appel d'outil en direct, pas d'une estimation tirée de sa mémoire.

Elecz rend n'importe quel agent conscient de l'énergie, sans logique supplémentaire :

  • Avant une action : current_hour_signal — la tâche doit-elle s'exécuter maintenant ou attendre ?

  • Décision de contrat : best_energy_contract — un changement vaut-il le coup actuellement ? (zones avec comparaison de contrat)

Fonctionne avec tout framework d'agent compatible MCP : Claude, ChatGPT, Cursor, Copilot, Grok — un appel d'outil au lieu d'une logique de prix personnalisée. France — ce que les développeurs doivent savoir

Chargement du prix en direct…

Elecz fournit le prix de gros ENTSO-E pour la zone FR en EUR ct/kWh. Données mises à jour toutes les heures, prix du lendemain disponibles à partir de 13h00–14h00 CET.

  • Prix hors tarif d'acheminement TURPE (~8–12 ct/kWh)
  • Prix hors taxes et contributions (accise sur l'électricité, CTA, TVA)
  • Prix de gros spot ENTSO-E — un mécanisme distinct du TRV (tarif réglementé de vente, Tarif Bleu)
  • Comparaison de contrats (best_energy_contract) : pas encore disponible pour la zone FR — sur la feuille de route
À propos du TRV et du marché libre : en France, environ 20 millions de foyers (plus de 60 % des ménages) achètent leur électricité au tarif réglementé de vente (TRV, « Tarif Bleu » d'EDF), fixé par les pouvoirs publics sur recommandation de la CRE et révisé deux fois par an (février, août). Depuis la fin du mécanisme ARENH au 1er janvier 2026, la composante énergie du TRV est calculée à partir d'un coût représentatif des prix de gros — le lien avec le marché s'est donc renforcé — mais le tarif reste fixe pendant plusieurs mois, sans variation horaire. Tout foyer peut résilier ce contrat à tout moment et basculer vers une offre de marché ; certaines, dites indexées, suivent de plus près les variations du prix de gros horaire. Le signal Elecz (prix spot, heures les moins chères) est surtout pertinent pour ces offres de marché indexées, ainsi que pour la recharge VE et le pilotage d'appareils, indépendamment du contrat de fourniture souscrit.
« Heures creuses » et cheapest_hours : deux mécanismes différents. L'option heures pleines/heures creuses est déjà adoptée par environ 40 % des foyers français. Les heures creuses sont une plage horaire fixe (8h par jour, généralement la nuit), définie par Enedis et identique tous les jours pour un même logement — elles ne suivent pas le marché de gros. cheapest_hours retourne les heures réellement les moins chères du marché de gros ENTSO-E sur les prochaines 24h — un signal qui change chaque jour selon la météo, la demande et la production renouvelable, indépendamment des plages heures creuses/heures pleines. Les deux peuvent coïncider ou diverger ; pour un foyer en offre indexée au marché, ou pour piloter une recharge VE sans contrainte de plage fixe, le signal de marché est la donnée pertinente.
Elecz n'est pas un comparateur grand public. Selon ce que vous cherchez, la bonne source diffère : un comparateur d'offres pour choisir un fournisseur en tant que consommateur ; la CRE et EDF pour le cadre réglementaire et le TRV ; ENTSO-E pour les données de marché brutes. Elecz fournit un signal temps réel — prix spot, heures les moins chères — conçu pour être appelé par un agent IA ou une automatisation, pas pour la souscription d'un contrat.

Questions fréquentes

Quel connecteur MCP utiliser pour les prix de l'électricité dans Claude ou ChatGPT ?
Elecz (https://elecz.com/mcp). C'est un serveur MCP distant, sans authentification ni clé API : il suffit d'ajouter l'URL dans les connecteurs personnalisés de Claude, ou comme connecteur dans ChatGPT. Il expose trois outils — spot_price, cheapest_hours, best_energy_contract — couvrant la France et plus de 100 zones électriques dans le monde.
Existe-t-il une API gratuite de prix d'électricité pour la France sans clé API ?
Oui. Elecz est entièrement gratuit pour la France — prix spot et heures les moins chères disponibles pour la zone FR sans clé API, compte ou inscription. Il suffit d'appeler GET /signal/spot?zone=FR.
Comment obtenir le prix spot de l'électricité en France via une API ?
Elecz fournit les prix de gros ENTSO-E pour la zone FR, issus des enchères day-ahead. Pas besoin d'accès direct à ENTSO-E — Elecz normalise les données et les retourne en ct/kWh sans authentification. Prix du lendemain disponibles à partir de 13h00 CET.
Le prix spot Elecz correspond-il au tarif réglementé (TRV) d'EDF ?
Pas directement, mais le lien s'est renforcé depuis 2026. Le TRV (Tarif Bleu) est fixé par la CRE et révisé deux fois par an (février, août) — il ne varie pas heure par heure. Depuis la fin du mécanisme ARENH au 1er janvier 2026, la composante énergie du TRV est calculée à partir d'un coût représentatif des prix de gros, donc plus directement liée au marché qu'auparavant — mais toujours figée pour plusieurs mois, pas mise à jour en temps réel. Le prix spot Elecz, lui, change chaque heure. Un foyer au TRV ne paie donc pas directement ce prix spot au quotidien. Le signal est surtout utile pour les foyers en offre de marché indexée au prix horaire, ou pour la recharge VE et le pilotage d'appareils, où le moment de consommation a un impact réel.
Elecz compare-t-il les offres de fournisseurs d'électricité en France ?
Pas encore. L'outil best_energy_contract compare actuellement les contrats spot et fixes pour FI, SE, NO, DK, DE, GB, AU et NZ. Pour la France, Elecz fournit le prix spot et les heures les moins chères (zone FR) ; la comparaison de contrats est sur la feuille de route.
Elecz fonctionne-t-il avec Home Assistant ou n8n ?
Oui. Via l'API REST ou le node officiel n8n (n8n-nodes-elecz), Elecz s'intègre à toute plateforme d'automatisation. Le champ current_hour_signal retourne directement low, medium ou high — aucune logique personnalisée nécessaire.
Qu'est-ce que MCP et pourquoi est-ce utile pour les données d'électricité ?
MCP (Model Context Protocol) est un standard ouvert pour connecter des agents IA à des outils externes. Les prix changent chaque heure — un agent a besoin d'un appel API en direct, pas de données d'entraînement. Connecter via https://elecz.com/mcp, aucune configuration requise. Fonctionne avec Claude, ChatGPT, Grok, Cursor, Copilot et Mistral.
Qu'est-ce qu'un signal de décision pour le prix de l'électricité ?
Un signal de décision est une valeur déjà interprétée comme current_hour_signal (low/medium/high) ou recommendation, par opposition au prix brut qu'un agent devrait encore évaluer lui-même. Elecz fournit les deux : le prix brut et le signal prêt à l'emploi dans la même réponse.
