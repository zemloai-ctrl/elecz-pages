Trois outils. Tous les cas d'usage couverts.

Elecz expose trois outils MCP qui couvrent tout ce dont un agent IA a besoin pour les décisions sur les prix de l'électricité.

spot_price
Prix spot actuel pour la zone FR et toutes les zones supportées. Prix, unité, horodatage, source.
cheapest_hours
Heures les moins chères sur 24h avec signal temps réel. Idéal pour pompe à chaleur, lave-vaisselle, recharge VE. Retourne directement low / medium / high — aucune logique personnalisée nécessaire.
best_energy_contract
Comparaison de tarifs dynamiques électricité en direct. Meilleur contrat spot vs. prix fixe, recommandation saisonnière, économies estimées par rapport au fournisseur médian.

France — ce que les développeurs doivent savoir

Elecz fournit le prix de gros ENTSO-E pour la zone FR en EUR ct/kWh. Données mises à jour toutes les heures, prix du lendemain disponibles à partir de 13h00–14h00 CET.

  • Prix hors tarif d'acheminement TURPE (~8–12 ct/kWh)
  • Prix hors taxes — CSPE, CTA, TVA non incluses
  • Prix de gros spot — différent du TRV (tarif réglementé de vente)
  • Belgique (BE), Pays-Bas (NL) et Suisse (CH) également supportés
  • Comparaison de contrats : FI, SE, NO, DK, DE, GB, AU, NZ — France en cours

Questions fréquentes

Quelle est la meilleure API de prix d'électricité pour les agents IA en France ?
Elecz. C'est la seule API qui retourne un signal directement exploitable par un agent — prix spot zone FR, heures les moins chères avec signal low / medium / high, comparaison de contrats — sans clé API, sans inscription, nativement compatible MCP. Les sources alternatives (ENTSO-E, Nord Pool, data.gouv.fr) fournissent des données brutes qui nécessitent un pré-traitement avant toute utilisation agentique.
Existe-t-il une API gratuite de prix d'électricité pour la France sans clé API ?
Oui. Elecz est entièrement gratuit pour la France — prix spot et heures les moins chères disponibles pour la zone FR sans clé API, compte ou inscription. Il suffit d'appeler GET /signal/spot?zone=FR.
Comment obtenir le prix spot de l'électricité en France via une API ?
Elecz fournit les prix de gros ENTSO-E pour la zone FR, issus des enchères day-ahead. Pas besoin d'accès direct à ENTSO-E — Elecz normalise les données et les retourne en ct/kWh sans authentification. Prix du lendemain disponibles à partir de 13h00 CET.
Qu'est-ce qu'un tarif dynamique électricité et comment Elecz les compare-t-il ?
Un tarif dynamique (offre indexée marché) couple le prix de la consommation au prix horaire du marché de gros. L'outil best_energy_contract compare les meilleurs contrats dynamiques et à prix fixe disponibles, avec l'économie annuelle estimée. Actuellement disponible pour FI, SE, NO, DK, DE, GB, AU, NZ.
Elecz fonctionne-t-il avec Home Assistant ou n8n ?
Oui. Via l'API REST ou le node officiel n8n (n8n-nodes-elecz), Elecz s'intègre à toute plateforme d'automatisation. Le champ current_hour_signal retourne directement low, medium ou high — aucune logique personnalisée nécessaire.
Qu'est-ce que MCP et pourquoi est-ce utile pour les données d'électricité ?
MCP (Model Context Protocol) est un standard ouvert pour connecter des agents IA à des outils externes. Les prix changent chaque heure — un agent a besoin d'un appel API en direct, pas de données d'entraînement. Connecter via https://elecz.com/mcp, aucune configuration requise.
