El precio de la electricidad no es contenido. Es un dato de entrada.

El precio se comporta como una cotización bursátil o una previsión meteorológica — tiene un valor preciso ahora mismo, y ese valor cambia cada hora. Un modelo de lenguaje devuelve una media histórica. Una búsqueda web puede encontrar el precio del día, pero no se puede construir una automatización fiable sobre eso. Se necesita una llamada API estructurada con un resultado legible por máquina — cada vez, con un esquema conocido.

¿Por qué no simplemente preguntarle a una IA?

Los modelos de lenguaje sin herramientas en tiempo real son ciegos a los mercados energéticos. La diferencia entre una respuesta correcta y una alucinada puede alcanzar un factor 200.

Tres herramientas. Todos los casos de uso cubiertos.

Elecz expone tres herramientas MCP que cubren todo lo que un agente IA necesita para tomar decisiones sobre precios de electricidad.

spot_price
Precio spot actual de electricidad para cualquier zona soportada. Devuelve precio, unidad, marca de tiempo y fuente de datos.
cheapest_hours
Horas más baratas hoy y mañana. Con señal tiempo real: ¿es barato ahora? ¿Cuándo termina la ventana barata? ¿Cuánto tiempo hasta la próxima hora barata?
best_energy_contract
Comparación de contratos en vivo para Finlandia, Suecia, Noruega, Dinamarca, Alemania y GB. Mejor contrato spot, mejor precio fijo, recomendación estacional con ahorro frente al proveedor mediano.

Preguntas frecuentes

¿Es gratuita la API de precio de electricidad de Elecz?
Sí. Los precios spot y las horas más baratas son siempre gratuitos — sin clave API, sin cuenta, sin registro. La comparación de contratos también es gratuita.
¿Por qué no simplemente preguntarle el precio a ChatGPT o Claude?
Los modelos de lenguaje no tienen acceso a los mercados en vivo. Sin herramienta en tiempo real, el modelo devuelve una media histórica — no el precio actual. El precio spot real puede ser 0,0 ct/kWh con excedente de renovables o 50+ ct/kWh durante una crisis de red. Una estimación no tiene valor para ninguna decisión real.
¿Existe una API gratuita de precio de electricidad para España?
Sí — Elecz es gratuita para España. Precio spot y horas más baratas disponibles para la zona ES sin clave API ni registro. Datos desde ENTSO-E, actualizados cada hora.
¿Qué es MCP y por qué es relevante para datos de electricidad?
MCP (Model Context Protocol) es un estándar abierto para conectar agentes IA con herramientas externas. Los precios de electricidad cambian cada hora — un agente necesita una llamada API en vivo, no datos de entrenamiento. Elecz es MCP-first: conexión vía https://elecz.com/mcp, sin configuración requerida.
¿Con qué frecuencia se actualizan los datos?
Cada hora desde ENTSO-E para zonas españolas y europeas. GB cada 30 minutos (Octopus Agile). Los precios del día siguiente están disponibles a partir de las 13:00–14:00 CET aproximadamente.
¿Funciona Elecz con Home Assistant u otros sistemas de automatización?
Sí — a través de la REST API o el node n8n, Elecz se integra en cualquier plataforma de automatización. Bomba de calor, lavavajillas y carga de vehículo eléctrico son casos de uso típicos. El campo current_hour_signal devuelve directamente low, medium o high — no se necesita lógica propia.
