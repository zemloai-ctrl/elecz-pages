Tres herramientas. Todos los casos de uso cubiertos.

Elecz expone tres herramientas MCP que cubren todo lo que un agente IA necesita para decisiones sobre precios de electricidad.

spot_price
Precio spot actual para la zona ES y todas las zonas soportadas. Precio, unidad, marca de tiempo, fuente.
cheapest_hours
Horas más baratas en 24h con señal tiempo real. Ideal para bomba de calor, lavavajillas, carga VE. Devuelve directamente low / medium / high — sin lógica propia.
best_energy_contract
Comparación de tarifas dinámicas en vivo. Mejor contrato spot vs. precio fijo, recomendación estacional, ahorro estimado. También vía REST: GET /signal/contract

España — lo que los desarrolladores deben saber

Elecz proporciona el precio mayorista ENTSO-E para la zona ES en EUR ct/kWh. Datos actualizados cada hora, precios del día siguiente disponibles a partir de las 13:00–14:00 CET.

  • Precio sin incluir peajes de acceso y cargos de red
  • Precio sin incluir impuestos — IVA, impuesto eléctrico no incluidos
  • Precio mayorista spot — diferente a la tarifa regulada PVPC
  • Mercado gestionado por OMIE, datos via ENTSO-E Transparency Platform
  • Portugal (PT) también soportado — mismo mercado ibérico MIBEL

Preguntas frecuentes

¿Existe una API gratuita de precio de electricidad para España sin clave API?
Sí. Elecz es completamente gratuito para España — precio spot y horas más baratas disponibles para la zona ES sin clave API, cuenta ni registro. Basta con llamar a GET /signal/spot?zone=ES.
¿Cómo obtengo el precio spot de la electricidad en España vía API?
Elecz proporciona los precios mayoristas ENTSO-E para la zona ES, basados en las subastas del mercado ibérico OMIE. Sin necesidad de acceso directo a OMIE o ENTSO-E — Elecz normaliza los datos y los devuelve en ct/kWh sin autenticación. Precios del día siguiente disponibles a partir de las 13:00 CET.
¿Qué es una tarifa dinámica de electricidad y cómo las compara Elecz?
Una tarifa dinámica indexa el precio del consumo al precio horario del mercado mayorista. La herramienta best_energy_contract compara los mejores contratos dinámicos y de precio fijo disponibles, con el ahorro anual estimado. Disponible para FI, SE, NO, DK, DE, GB, AU, NZ. También vía REST: GET /signal/contract?zone=DE&consumption=3500
¿Funciona Elecz con Home Assistant o n8n?
Sí. A través de la REST API o el node oficial n8n (n8n-nodes-elecz), Elecz se integra en cualquier plataforma de automatización. El campo current_hour_signal devuelve directamente low, medium o high — sin lógica personalizada necesaria.
¿Qué es MCP y por qué es útil para datos de electricidad?
MCP (Model Context Protocol) es un estándar abierto para conectar agentes IA con herramientas externas. Los precios cambian cada hora — un agente necesita una llamada API en vivo, no datos de entrenamiento. Conectar vía https://elecz.com/mcp, sin configuración requerida. Compatible con Claude, Grok, Cursor, Copilot y Mistral.
