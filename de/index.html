Strompreis ist kein Inhalt. Er ist ein Eingabewert.

Der Preis verhält sich wie ein Börsenkurs oder ein Wetterbericht — er hat genau jetzt einen präzisen Wert, und dieser Wert ändert sich stündlich. Ein Sprachmodell liefert einen historischen Durchschnitt. Eine Websuche findet vielleicht den heutigen Preis, aber darauf lässt sich keine zuverlässige Automatisierung aufbauen. Dafür braucht man einen strukturierten API-Aufruf mit maschinenlesbarem Ergebnis — jedes Mal, mit bekanntem Schema.

Warum nicht einfach eine KI fragen?

Sprachmodelle ohne Echtzeit-Tools sind blind für Energiemärkte. Der Unterschied zwischen einer korrekten und einer halluzinierten Antwort kann Faktor 200 betragen.

Deutschland — was zu beachten ist

Elecz liefert den ENTSO-E-Großhandelspreis für Deutschland (DE-LU Zone) in EUR ct/kWh brutto.

Diese Seite beschreibt hauptsächlich den deutschen Markt (Zone DE). Österreich (AT) und die Schweiz (CH) werden ebenfalls unterstützt — Spotpreise und günstigste Stunden verfügbar, Vertragsvergleich derzeit nur für Deutschland.

  • Preis exklusive Netzentgelt (~10–15 ct/kWh, regional unterschiedlich)
  • Preis exklusive Steuern und Abgaben (EEG-Umlage, Konzessionsabgabe etc.)

Häufig gestellte Fragen

Ist die Elecz Strompreis API kostenlos?
Ja. Spotpreise und günstigste Stunden sind immer kostenlos — kein API-Key, kein Account, keine Registrierung. Vertragsvergleich ist ebenfalls kostenlos.
Warum kann ich ChatGPT oder Claude nicht einfach nach dem Strompreis fragen?
Sprachmodelle haben keinen Zugriff auf Live-Märkte. Ohne Echtzeit-Tool liefert das Modell einen historischen Durchschnitt — kein aktueller Preis. Der tatsächliche Spotpreis kann 0,0 ct/kWh bei erneuerbarem Überschuss oder 50+ ct/kWh während einer Netzkrise betragen. Eine Schätzung ist für jede reale Entscheidung wertlos.
Gibt es eine kostenlose Strompreis API für Deutschland?
Ja — Elecz ist für Deutschland kostenlos. Spotpreis, günstigste Stunden und Vertragsvergleich sind für Zone DE ohne API-Key oder Registrierung verfügbar. Daten von ENTSO-E, stündlich aktualisiert.
Was ist MCP und warum ist es für Stromdaten relevant?
MCP (Model Context Protocol) ist ein offener Standard zur Verbindung von KI-Agenten mit externen Tools. Strompreise ändern sich stündlich — ein Agent braucht einen Live-API-Aufruf, keine Trainingsdaten. Elecz ist MCP-first: verbinden über https://elecz.com/mcp, kein Setup erforderlich.
Wie häufig werden die Daten aktualisiert?
Stündlich von ENTSO-E für deutsche und europäische Zonen. GB alle 30 Minuten (Octopus Agile). Folgetagespreise sind ab ca. 13:00–14:00 Uhr MEZ verfügbar.
Funktioniert Elecz mit Home Assistant oder anderen Automatisierungssystemen?
Ja — über die REST API oder den n8n-Node lässt sich Elecz in jede Automatisierungsplattform integrieren. Wärmepumpe, Geschirrspüler und EV-Ladung sind typische Anwendungsfälle. Das current_hour_signal-Feld gibt direkt low, medium oder high zurück — keine eigene Logik notwendig.
